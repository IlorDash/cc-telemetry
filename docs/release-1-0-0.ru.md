Это первый выпуск. В нём весь стек так, как его описывает руководство: сервер, который хранит
телеметрию Claude Code, скрипт для каждого ПК, который её отправляет, и семь дашбордов Grafana,
которые её показывают.

## Что нового

**Сервер на Windows или Linux.** Один скрипт запускает OTel Collector, ClickHouse и Grafana в
Docker и проверяет, что они отвечают. На Windows он использует Docker Desktop или Docker Engine
внутри WSL2 и ставит Docker в WSL, если вы согласны. На Linux он ставит Docker на Debian и
Ubuntu. Каждый запуск безопасен на уже настроенном сервере: `.env` не создаётся заново, данные
не удаляются. См. [Установка сервера](server.md).

**Доступ из сети — по вашему выбору.** По умолчанию сервер на Windows принимает данные только с
этого ПК; `-EnableLan` после запроса UAC открывает порты OTLP для локальной сети. Сервер на
Linux по умолчанию доступен из локальной сети; `--local-only` оставляет его только на этом ПК.
У портов OTLP нет аутентификации, поэтому режим локальной сети включайте только в доверенной
сети. См. [Порты и доступ на Linux](server.md#порты-и-доступ-на-linux).

**Клиенты на Windows или Linux.** Один скрипт на каждый ПК вносит настройки телеметрии в ваш
`settings.json` и сохраняет все остальные ключи. Перед первым изменением сохраняется копия
`<file>.bak`, а `-WhatIf` / `--dry-run` показывает результат, ничего не записывая. См.
[Подключение ПК](clients.md).

**Названия сессий, git-ветки и проекты.** Небольшой хук после промпта отправляет название
сессии, git-ветку и рабочую папку. Сервер определяет проект по явной метке, рабочей папке или
путям к файлам сессии. См.
[Названия сессий, git-ветка и рабочая папка](clients.md#названия-сессий-git-ветка-и-рабочая-папка)
и [Проект](clients.md#проект).

**Семь дашбордов и боковая панель.** Обзор, Сессии, Промпты, Эффективность, Агенты и навыки,
Инструменты и файлы и Состояние показывают стоимость, работу кэша, промпты, инструменты, субагентов и
состояние API. Панель слева переключает между ними и сохраняет период времени и переменные. См.
[Чтение дашбордов](dashboards.md).

**Дашборды на русском.** У каждого дашборда есть русская копия в папке Grafana `ru`. Кнопка
**RU** / **EN** в строке элементов управления переключает дашборд и его копию, период времени и
переменные сохраняются. Переведены боковая панель, названия панелей, переменных и колонок и
описания. Не переведены собранные данные (например, названия сессий), интерфейс самого Grafana,
названия и тексты подсказок и термины вроде `cost_usd` и TTFT. См.
[Русские дашборды](dashboards.md#русские-дашборды).

**Подсказки.** Восемь правил смотрят на последние 7 дней и называют то, на что стоит взглянуть,
например низкую долю попаданий в кэш или файл, прочитанный много раз. Подсказка открывает панель
с доказательствами. См. [Подсказки](tips.md).

**Обновление, резервная копия, откат.** На Linux `--update` сохраняет таблицы, подтягивает новую
версию, перезапускает изменённое и после этого сравнивает число строк; если в таблице строк
стало меньше, он печатает `FAIL`. `linux-server-tools/backup.sh` сохраняет и восстанавливает
собранные данные. См. [Обслуживание сервера](maintenance.md).

**Руководство на английском и русском.** Этот сайт, собранный из одного набора страниц на двух
языках.

## Данные и приватность

| Что | Поведение |
| --- | --- |
| Где хранятся | Только на серверном ПК, бессрочно; у коллектора нет экспортёра, кроме ClickHouse |
| Промпты | Хранятся при `OTEL_LOG_USER_PROMPTS=1`, который выставляет клиентский скрипт. Уберите переменную, чтобы прекратить |
| Ответы Claude | Полный текст коллектор удаляет до сохранения; остаётся только длина |
| Хук сессий | Отправляет название, git-ветку, рабочую папку и версию; никогда промпты и ответы. `-NoSessionMeta` / `--no-session-meta` его удаляет |

Полный список — на странице [Данные и приватность](data.md#что-отправляет-claude-code).

!!! note "Требования"
    На каждом клиенте нужен Claude Code **2.1.310 или новее**: в старых версиях события
    инструментов не содержат `agent_id`.
